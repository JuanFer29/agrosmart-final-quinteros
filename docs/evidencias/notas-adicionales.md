# Evidencias adicionales

## Problema con el file encoding

Durante el desarrollo tuve un problema con el file encoding del proyecto. El archivo estaba en codificación ISO-8859-1 y cuando intenté cambiarla desde IntelliJ la opción aparecía deshabilitada, por lo que no podía modificarla desde ahí. Después de revisar el problema encontré otra forma de corregirlo y el proyecto volvió a compilar y ejecutarse normalmente.

## Ejemplo de Cacao



En el comando `curl` utilizado para probar el endpoint que genera el eslogan con IA aparece el ejemplo "Cacao fino de aroma". Esto pasó porque reutilicé parte del código durante el desarrollo y en esa parte se fue de esa manera. Pero no afecta el funcionamiento del proyecto, mas es en el sentido que no tiene mucha relación.
